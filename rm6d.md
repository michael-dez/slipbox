`zk` is an executable that indexes markdown notes based on yaml frontmatter. Read the [zk docs](
https://github.com/mickael-menu/zk) to learn about configuration.

## Commands
Initialize a `zk` directory
```bash
zk init
```

Create a new note
```bash
# aliased to zn
zk new
```

Index notes
```bash
# aliased to zi
zk index
```

Find and edit a note with fuzzy finder
```bash
# aliased to ze
zk edit -i
```
