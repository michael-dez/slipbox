A file encryption tool by the same guy who created `mkcert`. What makes it stand out?
- It's a tool and a format
- Easy to use
- Lets you encrypt with an ssh key (who doesn't have one of those?)
- Let's you specify recipients

Using ssh keys is more convenient with the tradeoff of fewer features and greater complexity (under the hood I assume). Make an age key with `age-keygen`.
