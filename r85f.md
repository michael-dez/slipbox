`rsync` can be used as an alternative to `cp` and `scp`. `rsync` excels at [syncing files between machines](https://rsync.samba.org/tech_report/) which makes it a great tool for backups. `rsync` has many useful options, read through its [man page](https://linux.die.net/man/1/rsync)

## Backups
For security it's important to note that rsync can perform transfers using protocols other than ssh, so it's best to specify ssh explicitly. 

Here's a good example backup cronjob from the [arch wiki](https://wiki.archlinux.org/title/rsync#Automated_backup_with_SSH):
```bash
#!/bin/sh
rsync -a --delete --quiet -e ssh /path/to/backup remoteuser@remotehost:/location/of/backup
```

The same example as a Kubernetes cronjob running hourly:
```yaml
apiVersion: batch/v1
kind: CronJob
metadata:
  name: backup
spec:
  jobTemplate:
    metadata:
      name: backup
    spec:
      template:
        spec:
          containers:
          - image: alpine
            name: backup
            command:
            - bin/sh
            - -c
            - apk add rsync;
            - rsync -a --delete --quiet -e ssh /path/to/backup remoteuser@remotehost:/location/of/backup
          restartPolicy: OnFailure
  schedule: 0 * * * *
```
