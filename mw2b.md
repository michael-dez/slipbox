## Info vs texinfo vs tex
 **Texinfo** - Source language `info` docs are written in, extension `.texi`).
 **Info** Both the reader (`info`) and file format `*.info`
 **TeX** Typesetting engine; provides formatting for print media.

`info info` is lowkey very helpful.
