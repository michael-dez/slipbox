tcpdump

2026-05-12
clitroubleshootingnetworking

Captures packet info. Notable options are -i for interface and port which doesn't use a hyphen but works like an option in that it specifies the port to capture on and whether to listen for tcp and/or udp.

# writes packets coming into port 443 over tcp to pcap file
tcpdump -i eth0 port 443/tcp \
-w packetes.pcap \
-Q in
