Boot Manager (F11)

  • Notable options in Boot Manager:
    • BIOS Boot Menu and UEFI Boot Menu
    • Launch Lifecycle Controller
    • Launch System Setup
  • Since Boot Manager allows access to the other two startup options from it's splash page, it's a good button to mash when unsure

Lifecycle Controller (F10)

  • opens Lifecycle Controller

System Setup (F2)

  • opens System Setup
