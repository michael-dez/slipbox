Help

  • always learn help first
  • run go help <subcommand> to read about the use and options of the particular subcommand
  • go help offers help for more than just the go-cli commands, find out what by running the command without arguments

The go get command

  • prior to ~v0.16 go get would build and install a package, now go get only adjusts dependencies in the go.mod file
  • go get:
    • adds a "require directive" to the go.mod file
    • downloads dependency (module) source code so that it can be compiled with your project
  • I have no idea where the source goes ¯\_(ツ)_/¯

The go install command
