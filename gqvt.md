The goal of my note taking process is to make my notes useful, easy to find, and quickly written. My method is loosely based on the Zettlekasten Method.

## Tools
- neovim + [zk-nvim](ibuy)
- [zk](rm6d)
- git

## Process
I use short automatically generated filenames and search for existing notes using their front matter (title, tags, date). I also use a default template for new notes. The `zk-nvim` neovim plugin enables completion for wiki style links to other notes and automatically converts them to markdown style links.

## Style
I try to loosely follow the [Kubernetes Documentation Style Guide](https://kubernetes.io/docs/contribute/style/style-guide/#markdown-elements).
