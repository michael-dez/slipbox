## Variable declaration with implicit initialization
- in the example, `s, sep` are initialized with the 0 value of their type
- since type is `string` the zero value is an empty string
```
/* 
you can declare multiple variables at once,
comma separated,
ending with type
*/

var s, sep string
```
## Explicit variable initialization
- pass an initialization value instead of defaulting to one
```
s, sep = "hello world"
```
## Short variable declaration and initialization
- the type is guessed based on the initialization value
```
s, sep := "hello world"
```
