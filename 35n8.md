Alias kubectl.
```bash
alias k=kubectl
```
Practice creation of a basic vim config.
```vimscript
# ~/.vimrc
syntax on
set et ai nu rnu sw=2 ts=2 sts=2
```
Or in one line.
```bash
echo "set et ai nu rnu sw=2 ts=2 sts=2" > ~/.vimrc
```
Pipe output yaml directly to vim. Write to a file with `:w <filename>` if needed or `ZQ` if not. Allows vim to be used as a pager or editor.
```bash
k get po -n foo-ns foo -o yaml | vim -
```
