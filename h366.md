## Working directory
Create a project directory within your `$GOPATH' and change to the directory.
```bash
mkdir ~/go/src/<project-name>
cd ~/go/src/<project-name>
```

## Create a `go.mod` file
```bash
go mod init <chosen/module/path>
```
